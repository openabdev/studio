# Studio

Web UI for [openab](https://github.com/openabdev/openab) — start using openab
easily and control multiple fleets from one place.

## The idea

**Agents do the control. Humans direct.**

You set the intent and approve what matters; agents carry it out. Studio is the
**director's console** — one place to see your fleets and steer them, and a thin
front-end over the openab operator core (it surfaces control, it doesn't
reinvent it).

> **Status:** early / greenfield. Interfaces are still being defined.
